# Introduction

__Build__: 

- Put your own GITHUB_TOKEN into `local.properties`.
- Create your own keystore.jks to build the release apk if possible; otherwise, please contact the author.

__Icons__: Multiple libraries are used in order to provide all necessary icons.

- Material Icon Extended
- Free FontAwesome Icons
